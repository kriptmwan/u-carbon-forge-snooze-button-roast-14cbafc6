A make.fun competition entry: one line roasting an alarm clock for ringing at 6 AM on a Saturday morning.

## Entry

> My alarm clock rang at 6 AM on a Saturday, so I reported it for harassment — it snoozed the investigation.

106 characters. The clock gets reported for harassment, then uses its own snooze button to dodge the investigation — a bureaucratic punchline that turns the alarm's signature feature against it.

## How it works

`main.ts` validates the roast (1–200 characters, not only whitespace, counted in code points) and writes it to `/output/entry.txt`.

Run with Node 22:

```sh
node main.ts
```
